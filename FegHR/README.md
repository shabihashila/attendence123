# FegHR

The FEG-branded DailyHR fork uses a modular ASP.NET Core API, SQL Server row-level tenant security, and Angular 21 with PrimeNG.

See the [solution setup guide](../README.md) for the installer, demo credentials, SQL scripts, service addresses and deployment. See [architecture](../docs/ARCHITECTURE.md) for module boundaries and data contracts.

Build from the solution root with `dotnet build FEG-MICROSERVICES.slnx`. Build the UI with `npm run build` inside `Ui/FegHR.Ui`.
